# اختبار أحكام التجويد التفاعلي

اختبار إلكتروني تفاعلي (5 أسئلة عشوائية) في أحكام النون الساكنة والتنوين والميم الساكنة،
مع مؤقت 10 دقائق، وتقرير نتيجة مفصّل، وإرسال النتيجة إلى بريد المعلم تلقائياً.

## الرابط المباشر

https://orabi20266.github.io/quiz1/

## طريقة التشغيل

افتح الرابط أعلاه من أي متصفح. لا يحتاج المشروع إلى أي تثبيت أو خادم.

- الملف الرئيسي: `index.html`
- GitHub Pages: من فرع `main` / المجلد الجذري (`/`)

## تفعيل الإرسال التلقائي للنتائج (مرة واحدة)

كل إعدادات الإرسال في أعلى كود JavaScript داخل `index.html`:

```js
const RESULT_CONFIG = {
    teacherEmail: "",       // بريد المعلم الثابت (يُخفى الحقل عن الطالب)
    web3formsKey: "",       // مفتاح Web3Forms المجاني
    appsScriptUrl: ""       // رابط Google Apps Script (اختياري)
};
```

### الخيار الأول: Web3Forms (موصى به — مجاني 250 رسالة شهرياً)

1. افتح https://web3forms.com وسجّل ببريد المعلم.
2. فعّل بريدك من الرسالة التي تصلك، وانسخ **Access Key**.
3. ضع المفتاح في `web3formsKey`، وبريد المعلم في `teacherEmail`.
4. احفظ الملف وارفعه إلى المستودع.

بعد ذلك تُرسل النتيجة تلقائياً بمجرد تسليم الطالب، دون أي تدخل منه.
المفتاح ليس سرّاً ويمكن نشره داخل الصفحة (هذا هو استخدامه الرسمي).

### الخيار الثاني: Google Apps Script + Google Sheets (مجاني بالكامل)

1. أنشئ جدول Google جديداً من https://sheets.new.
2. من `Extensions ← Apps Script` الصق محتوى `apps-script/Code.gs`.
3. عدّل `TEACHER_EMAIL` إلى بريد المعلم.
4. `Deploy ← New deployment ← Web app`، مع:
   - Execute as: **Me**
   - Who has access: **Anyone**
5. انسخ رابط `/exec` وضعه في `appsScriptUrl`.

بهذا تُسجَّل كل نتيجة في الجدول وتُرسل رسالة إلى المعلم.

### الاحتياطي

إذا لم يُضبط أي من الخيارين، يحاول الموقع الإرسال عبر FormSubmit تلقائياً،
وإن تعذّر ذلك يعرض للطالب أزرار: نسخ التقرير، حفظه كملف نصي، أو إرساله عبر تطبيق البريد.

## منع إعادة الاختبار

يُسجَّل إتمام الاختبار في `localStorage` داخل المتصفح نفسه (حماية محلية لكل جهاز/متصفح).

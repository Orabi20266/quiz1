# اختبار أحكام التجويد التفاعلي

اختبار إلكتروني تفاعلي (5 أسئلة عشوائية) في أحكام النون الساكنة والتنوين والميم الساكنة،
مع مؤقت 10 دقائق، وتقرير نتيجة، وإرسال النتيجة إلى بريد المعلم.

## الرابط المباشر

https://orabi20266.github.io/quiz1/

## طريقة التشغيل

افتح الرابط أعلاه من أي متصفح. لا يحتاج المشروع إلى أي تثبيت أو خادم.

- الملف الرئيسي: `index.html`
- GitHub Pages: من `main` / المجلد الجذري (`/`)

## ملاحظة حول إرسال النتيجة بالبريد

يُرسل التقرير تلقائياً عبر خدمة FormSubmit. عند استخدام بريد معلم جديد لأول مرة،
تصله رسالة تفعيل (Activate) يضغط عليها مرة واحدة فقط.
وإن تعذّر الإرسال التلقائي، تظهر أزرار بديلة: الإرسال عبر تطبيق البريد، نسخ التقرير، وحفظه كملف نصي.

## منع إعادة الاختبار

يُسجَّل إتمام الاختبار في `localStorage` داخل المتصفح نفسه (حماية محلية لكل جهاز/متصفح).
